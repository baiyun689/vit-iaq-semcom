## 创新点 1：抗级联重要性感知源编码

### 问题

重要性感知语义通信中，动态比特分配产生变长码流。发端必须传输"每段多长"的元信息——元信息受损 → 收端游标偏移 → 后续所有 patch 从错误位置读比特 → 整图崩塌。这是"自适应分配 ⇔ 元信息脆弱"的**结构性矛盾**：

- 传统方案① CRC + ARQ：延迟敏感场景不适用
- 传统方案② UEP（元信息强 FEC）：概率性，SNR 低到某点照样崩，且 FEC 膨胀吃掉载荷预算
- 传统方案③ 固定码率（均匀分配）：放弃重要性自适应优势

本创新提出**结构性免疫**方案——让级联在源编码结构上就不可能发生，而非在概率上降低出错可能。

### 方法：非级联粗桶编码

**两层结构**：

- **基础层**：每 patch 固定 m_base bit 均匀量化。定长、固定位置、解码不依赖任何元信息。双用：粗图先验 + 收端派生排序的来源。
- **增强层**：固定大小固定比特的桶。按注意力降序把 patch 填入桶（如 top-49→4bit, 次-49→2bit, 其余→1bit），增强码流按桶配置定长排布。收端游标推进**只看桶配置（已知常数），不看"哪个 patch 落在哪个位置"**。

**关键性质**：
- 游标步长由桶配置唯一确定——即使收端排序与发端不一致，游标也按同一固定步长推进 → **结构上永不失步**
- 派生排序若与发端不一致，只是把某秩槽的细节值贴给了相邻 patch（**局部值错配**），绝不级联扩散
- 均匀量化嵌入式性质：T bit 量化索引的高 m_base 位 = m_base bit 索引 → 基础层 + 增强层重组 = T bit 精度

**收端派生排序**：解基础层 → 在基础层重建图上算注意力 → 降序 → 入桶 → 定长解增强层。与发端若一致则无损重组，若不一致仅局部错配。

- ① 均匀分配（无自适应基线）——保留动态重要性红利  
- ⑥ IAQ+FEC（经典修法）——结构防 vs 概率防

## 创新点 2：任务驱动收端语义修补

### 问题

非级联编码消除级联，但信道误码仍造成局部值错配（增强细节贴给相邻 patch）。传统错误隐藏用 MSE / 插值等信号层指标修复——不知道什么对下游分类任务重要。**前序教训**（A1）：用"逼近干净图注意力"做代理目标 → 注意力被摊平 → 准确率倒退。结论：代理目标不可靠，必须用任务损失直接训练。

### 方法：轻量 patch-Transformer 修补网络

**架构**（刻意轻量——证明增益来自设计原则非模型规模）：
- patch embed (768→192) + 比特深度 Embedding + 位置编码
- 4 层 TransformerEncoder (dim=192, heads=3, FFN=768)
- LayerNorm + Linear 投影回 patch 维度，输出残差

**三个设计原则**：

1. **可靠性感知**：比特深度图（bucket 解码免费副产品，标记各 patch 实得比特数）经 Embedding 注入每个 patch token。低比特 patch → 更不可信 → 修补网络重点依赖上下文修复。

2. **任务驱动训练**：损失 = 分类交叉熵（主）+ 重建 MSE（辅）。冻结分类裁判 + patch_embed，只训修补网络。梯度经 repaired 图回流到修补器。**用分类任务定义"什么是重要的"**，不重蹈代理目标覆辙。

3. **安全兜底（残差 + 零初始化）**：残差结构（输出 = 输入 + 修正）+ head 零初始化（初始残差 = 0）→ 初始输出恒等于输入。最坏情况（网络未训 / SNR 极端）→ 退回到不修 = 粗桶地板。结构上保证 AI 不帮倒忙。

### 与创新点 1 的关系

粗桶编码为修补网络创造三个使能条件：
1. **结构化损伤**（而非完全垃圾）：级联崩 → 修补无可信上下文可工作；粗桶 → 损伤局部、结构完整 → 修补可行
2. **免费可靠性图**：告诉修补器"修哪里"，零额外带宽
3. **质量地板**：基础层保底 → 残差兜底有稳定下界

## 两个创新点的叙事结构（答辩 PPT 逻辑）

1. **背景**：重要性感知语义通信——用 ViT 注意力分配比特 → 压缩带宽保住精度
2. **问题**：发现一个被忽视的基础性问题——元信息脆弱性导致级联失步（展示 SSIM 对比图：IAQ 0.07 vs Bucket 0.54）
3. **创新点 1**（通信层面）：非级联粗桶编码——结构性免疫，让级联在结构上不可能发生
4. **创新点 2**（AI 层面）：任务驱动修补——把残余局部损伤补回来，零额外带宽
5. **协同与验证**：六线实验 + 消融，展示完整系统的 Pareto 最优
