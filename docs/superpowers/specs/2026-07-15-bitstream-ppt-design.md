# B392 发送码流结构图设计

## 沟通目标

答辩听众看完单页后，应能理解发送码流先由定长基础层组成，再拼接按重要性分档组织的增强层，并能从图中直接核对 b392 工作点的比特数计算。

## 页面内容

- 标题：发送码流由基础层和分档增强层组成
- 主图：一条从左到右的发送码流，依次为基础层和增强层。
- 基础层：196 patch × 768 标量 × 1 bit = 150,528 bit。
- 增强层第一档：49 patch × 768 标量 × 3 bit = 112,896 bit。
- 增强层第二档：49 patch × 768 标量 × 1 bit = 37,632 bit。
- 增强层第三档：98 patch × 768 标量 × 0 bit = 0 bit；用虚线空段表示该档不发送增强比特。
- 总计：150,528 + 112,896 + 37,632 = 301,056 bit = 392 × 768 bit。
- 分档说明：第一档最终为 4 bit/标量，第二档最终为 2 bit/标量，第三档最终为 1 bit/标量。

## 视觉设计

- 16:9 单页，浅色背景，使用原图分档配色：第一档红色、第二档橙色、第三档蓝色；基础层使用中性深灰。
- 主码流占页面中部，以长度比例表现基础层 150,528 bit、第一档增强 112,896 bit、第二档增强 37,632 bit。
- 下方用三组简化 patch 方格说明每档 patch 数和“基础 1 bit + 增强 bit = 最终 bit”的关系。
- 只使用“分档”，不出现 Bucket、分桶、粗桶等旧表述。
- 页面底部明确说明 b392 是每个标量维度上 196 个 patch 的分配总和，实际码流长度还需乘以 768 个标量。

## 验收标准

- 公式和总数计算正确。
- 发送顺序、层级关系和三档构成一眼可辨。
- 中文标题及公式无乱码、裁切、重叠或意外换行。
- PPT 中的图形和文字可编辑。
