## 建议子节标题

**2.3.X 级联脆弱性的结构消除：SSIM 分布与视觉证据**

---

## 正文（可直接用）

结构崩塌的定量表征。为量化级联崩塌对重建图像结构完整性的影响，在 Eb/N0 = 3 dB、B_target = 392、n = 256 的设置下，对同一批测试图像分别运行差异化裸传方案与粗桶非级联编码方案，逐图计算重建图像与原图的结构相似度，绘制分布直方图如图 3 所示。

[图 3 插入位置：outputs/ssim_distribution.png — Eb/N0=3dB 下差异化裸传与粗桶方案的 SSIM 分布直方图，B_target=392, n=256]

该分布图揭示了两种方案在结构完整性上的质的分野。差异化裸传方案的 SSIM 分布整体严重左偏，主峰位于 0.0–0.2 区间，均值仅 0.149，且向负值方向拖出长尾：最低达 −0.193，256 张图像中有 27 张 SSIM < 0，占比 10.5%。负 SSIM 意味着重建图与原图在统计意义上呈反相关——原本该亮的区域变暗、该暗的区域变亮，图像空间结构被系统性颠覆。这一现象是级联崩塌区别于普通信道噪声的独特诊断信号：随机噪声叠加仅模糊或污染图像内容，不会反转空间结构；而级联游标失步使后续所有 patch 从错误位置读取比特，等价于用随机排列的像素填充图像，在统计意义上可产生负 SSIM。

相较之下，粗桶方案的 SSIM 分布集中在 0.5–0.8 区间，均值 0.638，最小值 +0.266，零负值。尽管经历相同的 3 dB 信道噪声，得益于定长桶结构从根源上消除了级联失步的可能，所有重建图像均保持了与原图的正相关结构。

图 4 进一步给出了 0 dB 下两种方案的接收图像并排对比。差异化裸传方案的重建图呈现系统性结构崩坏：物体轮廓与纹理信息完全不可辨识，SSIM 均值仅 0.070。粗桶方案的重建图虽因低 SNR 而模糊，但空间布局与主体轮廓仍可辨识，从定性层面佐证了上述分布图的结论。

[图 4 插入位置：outputs/cliff_vs_bucket_n256_snr0.png — 0dB 下差异化裸传与粗桶方案的接收图像并排对比，Eb/N0=0dB, n=256]
