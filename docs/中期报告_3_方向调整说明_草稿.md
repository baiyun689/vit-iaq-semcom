3 研究方向的调整与说明

本课题在开题阶段拟定的研究方案为"面向图像重建与分类的端到端联合信源-信道编码方法研究"，技术路径是在 CNN-JSCC 基线中依次引入 DCT 频域语义增强与轴向自注意力机制，以强化编码器对判别性语义特征的提取与保持能力。该方案的底层假设是：端到端 JSCC 的性能瓶颈在于特征表示不够好——CNN 缺乏对频域线索的显式建模，且局部感受野限制了长程依赖的捕获。因此，改进方向自然地指向编码器结构的增强。

在实际研究推进过程中，一个未被开题方案预见的现象改变了上述判断。在调试显式重要性感知传输管线——即以 ViT 注意力分数指导各 patch 差异化比特分配的方案——时，我们发现：该方案在干净信道下较均匀分配有约 14 个百分点的显著增益，验证了"把比特用在更重要的地方"这一直觉；然而当分配向量作为元信息经噪声信道传输后，系统呈现断崖式崩塌——准确率从正常水平骤降至 1~3%，且崩塌一旦触发，全部差异化红利归零，甚至劣于不做任何差异化的均匀方案。进一步分析表明，这一崩塌的根源在于变长码流对元信息的结构性依赖：元信息中单个比特的差错会通过游标偏移沿码流向后传播，使后续所有 patch 的载荷段全部错位，是典型的级联失效模式。

这一发现促使我们重新审视研究焦点的优先级。DCT 频域增强与轴向注意力解决的是"特征够不够好"的问题，而元信息级联崩塌解决的是"系统能不能用"的问题——前者是增量优化，后者是生存性缺陷。在一个存在结构性崩塌的系统中，编码器特征的任何改进都可能被一次元信息错误完全抹除。因此，我们判断元信息脆弱性问题在逻辑上优先于特征增强问题：必须先消除级联崩塌的结构性成因，使系统退化行为从"悬崖式"变为"平滑式"，在此基础上才有意义讨论特征层面的进一步优化。

基于上述判断，本课题将研究重心从"编码器语义特征增强"调整为"元信息脆弱性分析与抗级联编码"。具体而言，中期阶段完成了三项递进工作：（1）形式化分析变长码流的游标失步机理，并通过定量实验表征崩塌的临界信噪比区间与损伤特征；（2）提出非级联分桶源编码方案，以"定长基础层 + 固定桶增强层"的码流结构替代变长游标，从根源上切断级联传播路径；（3）设计收端任务驱动语义修补网络，在零额外带宽条件下修复分桶方案的残余局部损伤。三项工作构成"发现问题→结构性消除→智能修补残余"的完整闭环，与开题方案中"模块移植→递进叠加"的技术路线存在范式层面的差异。

综上，研究方向的调整并非对开题方案的否定，而是在实验探索中发现了更具研究价值且逻辑上优先的问题。调整后的方案以具体现象（悬崖效应）为起点，以分析驱动设计，最终在匹配与失配信道条件下均实现了平滑退化的系统行为。开题方案中"端到端学习 + 语义保持"的基本理念在修补网络的训练策略中得到了延续——修补网络同样采用任务损失端到端驱动，但服务的对象从 CNN 编码器变为了分桶解码器。
