## 本次实际环境

Python 3.11.15；PyTorch 2.11.0+cu128；torchvision 0.26.0+cu128；timm 1.0.27；NumPy 2.4.4；SciPy 1.17.1。

实际GPU是 **NVIDIA GeForce RTX 4060 Laptop GPU，8GB**。5080不是本次实际验证设备。GPU检查使用4张训练图、2张选型图和2张审查图，批量2，修补模型仅训练1轮；这不能推断完整模型、批量8或全部数据的吞吐与显存需求。

真实分类器权重使用已存在的本地HF缓存，检查期间采用离线加载。外部分类器的完整训练数据接触范围没有被这次检查证明。
