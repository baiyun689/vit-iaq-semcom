2.2 节的分析表明，级联崩塌的根源在于变长码流对元信息 {M_i} 的结构性依赖。收端游标的每一步推进都由 M_i 决定，元信息中任何一个比特的差错都会沿码流向后传播，掀翻后续所有 patch。消除这一脆弱性的根本途径不是把元信息保护得更好，而是改变码流组织方式本身。基于这一判断，本节提出非级联分桶编码方案。方案追求三个目标：保留动态重要性分配的红利，不因消除级联退回到均匀分配；使收端码流解析不再依赖任何通过噪声信道传输的元信息；信道差错只造成局部损伤，不引发全局传播。

实现上述目标的核心思路是将每 patch 的传输比特组织为基础层和增强层两层。基础层承载每 patch 固定比特数的粗精度信息，按 patch 索引顺序定长排布，解码无需任何元信息。增强层将 patch 按注意力降序分入若干固定比特的桶，码流按桶的档位顺序依次拼接，各段的比特长度由桶配置唯一确定。收端在基础层重建图上重算注意力并自行排序，决定各段增强比特分别归属于哪些 patch。

基础层为每个 patch 分配固定的 m_base bit 均匀标量量化。以 b392 工作点为例，m_base = 1，每个标量获得 1 bit 基准精度。每 patch 含 P = 768 个标量，故单 patch 的基础层段长度恒为 P·m_base = 768 bit。全图基础层码流按 patch 索引顺序定长拼接，总长度 L_base = N·P·m_base 为收发双方先验已知的常数，收端直接按索引号乘段长定位各 patch 的起止位置。基础层承担两个关键职能。其一，提供粗精度重建图，供收端在其上重新运行 ViT 编码器派生排序。其二，提供系统精度的保底下界，即使增强层全部丢失，精度也不低于基础层的基准水平。

增强层将 patch 按注意力降序填入一组固定比特的桶。每档桶有确定的数量和每标量比特深度。以 b392 工作点为例，注意力最高的 49 个 patch 进入第一档，每标量 4 bit，其中基础层占 1 bit、增强层追加 3 bit；次高的 49 个 patch 进入第二档，每标量 2 bit，追加 1 bit；其余 98 个 patch 进入第三档，每标量 1 bit，不追加增强比特。三档合计满足 Σ M_i = 49×4 + 49×2 + 98×1 = 392 = B_target。

一般地，记 patch i 的注意力排名为 r(i) ∈ {1, …, N}（r = 1 为最高）。设桶配置由 K 档组成，第 k 档容纳 s_k 个 patch、每标量比特深度 d_k，Σ s_k = N。定义累计容量 C_k = Σ_{t=1}^{k} s_t（C_0 = 0），则 patch i 的每标量比特分配为

\[
M_i = d_k, \quad C_{k-1} < r(i) \leq C_k
\]

该式将注意力排名到比特深度的映射表达为桶配置唯一决定的阶跃函数：处于同一排名区间的 patch 获得相同比特深度，区间边界为收发双方预知的常数。

增强码流按桶档位顺序依次拼接，每档内部按注意力排名顺序排列，各排名位置的增强比特长度仅由该位置所属的桶档决定。以第一档为例，49 个排名各传输 P×3 bit 增强比特，收发双方均可直接从桶配置推算出这一长度。无论收端派生的排名与发端是否一致，游标在每个排名位置读取的比特数都是常数，因为该常数取决于桶配置而非具体是哪个 patch 排在此处。

上述机制的关键在于，增强层各段的长度是桶配置规定的固定值，不经信道传输，因而不受噪声影响。反观 2.2 节的裸传方案，收端游标步长依赖 M̂_i，而 M̂_i 经噪声信道传输后可能出错，一旦出错游标偏移，后续所有段的起止位置全部错位。分桶方案切断了这一依赖。增强层游标步长由桶配置常数决定，收发双方预知。收端派生排序只决定各段增强比特分配给哪些 patch，不参与游标步长的计算。即便排序偏差导致某段增强比特贴错了 patch，游标照常推进，后续各段不受牵连，差错被限制在局部。

收端解码基础层后，用与发端相同的冻结 ViT 编码器重新计算注意力分数，按降序将 patch 填入桶配置，由此确定增强层各段比特分别归属于哪个 patch。理想条件下派生排序与发端一致；基础层受损时排序可能产生偏差，造成增强比特归属错位——本该分配给高注意力 patch 的增强段被误贴到低注意力 patch，反之亦然。

记收端从基础层重建图派生的排名为 r̃(i)，对应的分配为 M̃_i = d_k（C_{k-1} < r̃(i) ≤ C_k）。定义 patch i 的分配偏差 ΔM_i = M̃_i − M_i（单位：bit/标量），其绝对值即为该 patch 因排序错位而错失的精度。全图平均错配幅度为

\[
\bar{\Delta} = \frac{1}{N}\sum_{i=1}^{N} |\tilde{M}_i - M_i|
\]

该量刻画了收端派生排序与发端排序不一致所导致的比特分配误差。

为量化上述偏差的实际影响，在干净信道下进行探针实验，条件为 n = 256、B_target = 392、m_base = 1。收端在基础层重建图上的派生排序与原始注意力排序的 Spearman 秩相关系数为 0.29，桶分配一致率 48%。端到端分类准确率上，收端派生方案较发端排序方案下降约 6 个百分点——近半 patch 桶归属出错，但准确率损失远小于错配比例，说明分类任务对排序偏差具有一定容忍度。注意力极高和极低的 patch 在 1 bit 精度下仍可大致区分，排序偏差集中在注意力中段，而中段 patch 落入同一桶的概率较高，桶分配结果变化有限。分桶方案在干净信道下较均匀分配提升约 9 个百分点，回收了全精度增量分配 14 个百分点增益的约 66%，余下损失为 metadata-free 的固有代价。

分桶方案将元信息从三个分量削减为零。每 patch 的比特分配向量 {M_i}（N·⌈log₂(M_max+1)⌉ = 784 bit）被桶配置常数取代，无需传输。umin 和 umax 由收发双方约定固定值 0 和 1，不再逐帧计算图像自适应最值——对 CIFAR-100 的 [0, 1] 归一化图像，该固定范围引入的量化效率损失极低。桶配置为系统级常数，收发双方预共享。至此，码流解析和反量化所需的全部参数均由双方独立导出或预约定，信道中不再传输任何元信息分量。

为量化分桶方案消除级联失步的实际效果，在 Eb/N0 = 3 dB、B_target = 392、n = 256 的设置下，对同一批测试图像分别运行 2.2 节的差异化裸传方案与本节分桶方案，逐图计算 SSIM，绘制分布直方图如图 3 所示。

[图 3 插入位置：outputs/ssim_distribution.png — Eb/N0=3dB 下差异化裸传与分桶方案的 SSIM 分布直方图，B_target=392, n=256]

该分布图揭示了两种方案在结构完整性上的质的分野。差异化裸传方案的 SSIM 分布整体严重左偏，主峰位于 0.0 至 0.2 区间，均值仅 0.149，且向负值方向拖出长尾，最低达 −0.193，256 张中有 27 张 SSIM < 0，占比 10.5%。负 SSIM 意味着重建图与原图在统计意义上呈反相关，图像空间结构被系统性颠覆。随机噪声叠加仅模糊或污染图像内容，不会反转空间结构；级联游标失步等价于用随机排列的像素填充图像，在统计意义上可产生负 SSIM。相较之下，分桶方案的 SSIM 分布集中在 0.5 至 0.8 区间，均值 0.638，最小值 +0.266，零负值。得益于定长桶结构从根源上消除了级联失步，所有重建图像均保持正相关结构。

分桶方案从码流结构上消除了级联失步，将级联崩塌的灾难性故障化为可控的局部错配，但派生排序偏差造成的归属错位和增强层信道误码仍各自引入残余损失。2.4 节将在收端引入轻量修补网络，利用分桶方案天然产出的比特深度图作为可靠性先验，零额外带宽地修复上述残余损伤。
