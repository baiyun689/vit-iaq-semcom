2.3 节的分桶方案从码流结构上消除了级联失步，将 2.2 节的灾难性崩塌化为可控的局部损伤。但"可控"不等于"消除"——两个残余损伤源仍然存在。其一，收端派生排序的偏差导致增强比特归属错位，约 48% 的 patch 被归入错误的桶。其二，增强层码流经过噪声信道，比特翻转引入量化误差。2.3 节的探针实验表明，仅归属错位一项就在干净信道下造成约 6 个百分点的准确率下降；叠加信道噪声后损失更大。本节在收端引入一个轻量语义修补网络，在零额外带宽的条件下修复上述残余损伤。

分桶方案天然为修补网络提供了三件可用的"免费资产"。第一，分桶编码的损伤是结构化的——比特归属可能错位、增强比特可能误码，但图像的空间布局和主体轮廓仍可辨识（2.3 节图 4），修补网络有可信的上下文可供利用，而非面对一片随机噪声。第二，收端解码增强层时必须先确定各段比特的归属，这一过程自然产出一张"比特深度图"——每个 patch 实际获得了多少 bit——这张图恰好标记了各 patch 的可靠程度：低比特 patch 更应依赖上下文而非自身信息。比特深度图是解码过程的免费副产品，无需额外传输。第三，基础层提供了一张粗精度重建图作为质量地板，修补网络最坏情况下可以退回到它。

修补网络的任务可形式化为：输入受损重建图 X̂ 和比特深度图 D（每 patch 一个整数，标记其实际获得的总比特数），输出残差修正 R，最终重建为 X̃ = X̂ + R，再交由冻结的分类器给出类别预测。

语义修补网络整体架构如图5所示。

![图5 语义修补网络架构](../outputs/repair_arch.png)

网络架构为轻量 patch-Transformer，参数约 2.1M。输入图像经 ViT 的 patch 划分（14×14 网格，每 patch 768 维）线性投影至 192 维 token。比特深度图 D 经 Embedding 层映射为同维度向量，逐 patch 加至对应 token，使低可靠 patch 的 token 携带"不完全可信"的身份标记。叠加上可学习的二维位置编码后，token 序列经 4 层 Transformer Encoder（维度 192，注意力头 3，FFN 768）传播上下文信息，最后经 LayerNorm 和线性 head 投影回 768 维，输出残差 R。输出 head 的权重和偏置在初始化时置零，使得未训练时 R = 0、X̃ = X̂，网络输出恒等于输入。

输出残差而非直接输出重建图，提供了结构层面的安全兜底。若网络直接输出 X̃ = Net(X̂, D)，则输出中不再保留 X̂ 的原貌——网络一旦出错，基础层粗图的信息被彻底覆盖，无法回退。残差结构 X̃ = X̂ + R 则不同：X̂ 通过 skip connection 原样抵达输出端，网络只负责输出修正项 R。这一设计的实际含义不在于训练——训练完成后网络的权重固定，R 的行为也就固定——而在于推理阶段提供了可逆的修补接口。若 R 的修正方向正确，则 X̃ 优于 X̂；若 R 的修正无效甚至有害，可将其丢弃，X̃ 退回 X̂，系统性能不下于粗桶地板。更细粒度地，甚至可以逐 patch 判断 R 的可信度，选择性施加修正。这一保证是结构性的：无论网络如何训练、在何等信道上推理，X̂ 的信息都不会被 R 修改所破坏。输出 head 的零初始化（R = 0 恒等起点）则是训练层面的配合：网络从"不修补"开始学习，偏离恒等的每一步都必须经分类损失的检验才被保留，客观上降低了训练出有害修正的风险。两者叠加——结构保证下限不破，训练控制起点平稳——将 AI 修补组件的安全边界收敛到"可提升、不恶化"。

训练策略遵循三个原则。原则一：可靠性感知。比特深度图经 Embedding 注入每个 patch token，使注意力机制在处理低可靠 patch 时天然倾向于从高可靠邻居借信息。原则二：任务损失驱动。以分类交叉熵为主损失，辅以重建 MSE（权重 λ = 0.1）。主损失直接优化端到端分类准确率，避免了代理目标与真目标背离的风险——此前的一项尝试以 KL 散度逼近干净图注意力为训练目标，结果学生网络的注意力被"摊平"、准确率反而倒退 7 个百分点，证实了代理目标的危险。原则三：只训修补器。冻结分类裁判 ViT 的全部权重，以及修补网络自身的 patch_embed 层（将每 patch 从 768 维线性投影至 192 维的输入层），梯度仅流入 Transformer Encoder 和输出 head。这保证了分类器本身的行为不变——修补网络学习的是"如何修正输入让分类器判得更准"，而非改变分类器的判断标准。

上述训练策略可形式化为以下优化目标。记修补网络参数为 θ_R，冻结的 ViT 分类器为 f_cls，受损重建图为 X̂、比特深度图为 D、残差为 R = Net_{θ_R}(X̂, D)、修补后重建为 X̃ = X̂ + R，干净原图为 X_clean，类别标签为 y。训练目标为：

    min_{θ_R}  E[ L_CE( f_cls(X̃), y )  +  λ · MSE( X̃, X_clean ) ]

其中 L_CE 为分类交叉熵损失，MSE 为逐像素均方误差，权重 λ = 0.1。期望 E 在 CIFAR-100 训练集和 [0, 12] dB 的随机信道实现上取值。分类器 f_cls 和 patch_embed 冻结，梯度仅通过 X̃ 流入 θ_R。

训练数据由 CIFAR-100 训练集经完整粗桶管线生成：每张图依次经过基础层编码、增强层分桶编码、BPSK 调制、AWGN 信道（Eb/N0 在 [0, 12] dB 区间随机采样）、解调、分桶解码，得到受损重建图和比特深度图。跨 SNR 训练使单个网络具备处理不同损伤程度的能力，无需逐 SNR 训练独立模型。训练约需 10 个 epoch，可在一台配备 GPU 的机器上完成。

跨 SNR 训练完成后，在测试集各 SNR 点评测修补前后的分类准确率。如图6所示，修补网络在 0~12 dB 范围内稳定贡献 20~25 个百分点的准确率增益，且该增益完全来自收端后处理，不占用任何额外信道带宽。

![图6 语义修补网络性能增益](../outputs/repair_gain.png)

修补网络与分桶编码之间形成三层次的协同。在数据层面，分桶提供结构化损伤而非随机噪声，使修补器有上下文可依。在信息层面，比特深度图标记可靠区域，指导修补器"修哪里"。在安全层面，基础层地板加残差兜底，保证修补器的输出下限。三个层次的协同使得分桶方案的残余损伤成为可学习、可修复的对象，而非不可控的随机错误。
