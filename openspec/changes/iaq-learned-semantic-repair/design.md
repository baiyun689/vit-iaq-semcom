## Context

IAQ 用 ViT 注意力给 patch 分配量化比特，重要 patch 多给 bit。要让收端按这套变长分配
反量化，必须知道每 patch 的比特深度（M_i 图）。把 M_i 过信道（创新点 A）一错就游标
失步、级联崩到随机猜（"元信息悬崖"）。前序 change `iaq-a1-metadata-free`（A1，收端从
基础层派生分配）已在实验中证伪：

- A1 派生需基础层**逐 bit 精确**才能两端一致，而任何有限 FEC 都给不了这个保证；
- A1 的增强层仍是变长游标 → 基础层错 1 bit 即级联崩（只是被基础层兜在底，非随机）；
- 用 KL 蒸馏干净图注意力去"修派生"的微调（§2.5）反而把注意力摊平、准确率倒退 7pt
  （代理目标与真目标背离）。

诚实结论：**变长 + 免传 + 抗误码三者在裸游标下不可兼得。** 本 change 改 AI-centric
思路解决之。旧探针（n=256）给出了分配可行性的线索，但不能证明真实收发排序错配的范围或修补收益。

约束（项目级）：中文交流与注释；本机 GPU 满载会过热，训练在另一台 GPU 机跑、本机仅
CPU 小样本；接受训练但不做 ImageNet 级（CIFAR-100 规模 OK）；新颖度求"不雷同"非首创。

## Goals / Non-Goals

**Goals:**
- 保留 IAQ 动态重要性分配，同时使增强码流读取边界不依赖接收端排序。
- 研究收端学习式语义修补能否改善任务性能，测量净增益、救回率与修坏率。
- 采用六线、共同信道比特上限、匹配/失配双场景对照，如实比较各方案，不预设优势。

**Non-Goals:**
- 当前仅用启发式重复码档位作基线，不把它当作最优 FEC，也不预设其匹配场景表现。
- 不做 ImageNet 级训练；不宣称跨数据集泛化（除非另测）。
- 不实现注水法分配、不引入 LDPC（FEC 用重复码即可）。
- 不保留 A1 的派生增强层机制（已证伪，留作反面对照与动机）。

## Decisions

### D1 源编码：均匀基础层 + 固定桶重要性增强层（非级联）
- **基础层**：每 patch m_base bit 均匀量化，**定长、无需排序**，破解"要排序先重建、
  要重建先知分配"的死循环；同时是粗图先验 + 派生排序的来源。
- **增强层**：按收端派生的注意力排序，把 patch 装进**固定大小、固定比特**的桶
  （例 b392：基础层 1bit×196；增强 top-49 +3bit / 次-49 +1bit / 其余 98 +0；
  增强码流 `[49×3][49×1]` 定长）。总 ΣM_i=392 = ρ0.25。
- **为何不级联**：增强层按固定位置读，永远对齐；派生排序若与发端不一致，只是把值
  归属到错误 patch，可能涉及大范围位置或同桶内交换；固定读取边界不受影响。
- **替代方案**：A1 变长游标（已证级联崩，弃）；纯均匀（丢重要性，弃）；定长满槽
  （退化≈均匀，弃）。固定桶是"保重要性 + 非级联"的最小公倍数。
- **历史探针记录（旧协议，不能替代新实验）**（n=256）：b392 下 增量(理想)0.613 / 均匀0.395 / 粗桶0.539 →
  **粗桶捞回 66% 重要性红利**；据基础层派生分桶 vs 据原图，**仅掉 2pt**，错配
  跨档统计曾报告 14%。这些是原图/基础层分配比较，不能推导真实传输错配局部化或 AI 一定可修。

### D2 收端派生排序（metadata-free，需测量归属错配）
收端解基础层 → 粗图 → 算注意力 → 排序入桶。这步的产物就是"比特深度图"，**收端
解码必然已算出**（解码要用），零额外传输开销。派生与发端不一致可能造成广泛数据归属错配。

### D3 学习式语义修补网络（创新核心）
- **结构**：轻量 patch-Transformer（几层自注意力），**像素/patch 域**输出残差修正
  （可视化友好、冻结分类器原样复用、好训）；本质 MAE/inpainting。
- **输入**：受损重建 patch 网格 + **比特深度图**（D2 的解码副产品，作为量化精度条件；不代表实测信道可靠性）。重要性在此**二次进场指导修复**，不再分配比特。
- **初始化**：零输出头使初始网络恒等。训练后残差可能有害，不保证性能下限。
- **训练**：冻结分类裁判 + patch_embed，**只训修补器**；数据 = CIFAR-100 过完整管线
  （粗桶编码→AWGN 随机 SNR→解码）；**损失 = 分类交叉熵(主) + 重建 MSE(辅)**，
  跨 SNR 训。⚠️ **直接用任务准确率当目标**，不重蹈 §2.5 代理目标摊平的覆辙。
- **替代方案**：纯 token-embedding 域（更抽象难调）；显式通信校验定位（沾通信开销）；
  单独训异常检测头（多部件、错则连累）。选"像素域 + 免费可靠性图 + 隐式修复"。

### D4 传统通信仅辅助、基础层 FEC 可选
固定边界使增强层读取位置不依赖基础层排序，但基础层错误仍会影响重建与排序；FEC 是可选保护，其收益必须测量。主实验默认不加 FEC（最干净的同带宽）；附加对照
单列"加轻 FEC 抬地板"并按 gauge B 记开销。

### D5 实验：六线、共同信道比特上限、双场景
- 六线：⓪理想(免费辅助信息参考，并非严格性能上界) / ①均匀(metadata-free 基线) / ③裸传元信息(悬崖) /
  ⑥IAQ+保护元信息(经典 FEC 修法) / ④粗桶(无修补) / ⑤粗桶+AI修补(本方案)。
- **同带宽记账**：全线总信道比特不超过 768×392，记录实际用量和未用预算；③⑥ 把元信息(+FEC)**从预算内扣**
  （源预算按实际元信息长度与重复码冗余扣减，不能假定其性能影响可忽略）；⓪ 与 ③ 同信源预算，
  唯一差别是元信息过不过信道 → **⓪−③ 隔离纯悬崖**；④−① 同时包含分层量化和排序错配影响；
  **⑤−④ 隔离 AI 增益（零额外带宽）**。
- **双场景**：匹配按当前 SNR 选重复码档位；失配按固定设计 SNR 选择档位再扫描真实 SNR。两者都如实呈现结果，不预设曲线形态。
- **消融**：AI 修补开/关(⑤vs④)；可靠性图开/关；粗桶+修补 vs 均匀+修补（重要性是否仍值）；
  跨 SNR 训 vs 单点训。
- **指标**：Top-1 vs 发送编码比特能量/N0；配对 AI 增益、救回率与修坏率；修补前后可视化；开销记账。

## Risks / Trade-offs

- [旧探针不能替代新协议验证] → 在独立验证集重做源编码与实际传输诊断，再选择桶配置。
- [结果可能不支持原假设] → 匹配与失配均报告，不能通过只选有利场景证明普遍优势。
- [极低 SNR 大部分 patch 损坏、上下文耗尽，AI 修不动] → 测量真实准确率及有害修补；不保证退回基础层地板。
- [b392 基础层只能 1bit，派生比探针(2bit)差] → 实现期用 m_base=1 重测钉死真实代价，
  检验修补能否改善；必要时调桶档位。
- [修补训练用代理目标会重蹈 §2.5 覆辙] → 用分类损失训练，并以配对验证跟踪有害修补。
- [训练吃 GPU、本机过热] → 训练在另一台 GPU 机跑，本机仅 CPU 小样本验证，先问后跑。

## Open Questions

- 2026-10-03 已完成 n=24、m_base=1、B=392 的 CPU 小样本扫描与探针。近无误码候选 98:3,98:1 为 15/24；6 dB 实际 5/24，而同受损码流 oracle 排序为 16/24。增强归属错配 97.5%，说明固定排名槽对排序扰动仍很敏感。原始结果见 `outputs/corrected/pilot_20261003/`。
- 桶配置尚未定型：先评估固定空间定位、降低组内排序依赖或保护必要定位信息的对照，计入全部开销，再扩大验证。不把本次候选当成最终最优方案。
- 修补网络规模/层数与训练 SNR 区间的最优配置，实现期调。
- 失配场景的设计 SNR 与 FEC 档位在验证集确定，不能按最终测试结果挑选。

### D6 训练进度与验证选择
训练按轮次验证，固定验证样本和信道种子，以各 SNR 的平均修补后准确率选优。
最佳模型与最新进度分开保存；最新文件包含最佳模型、优化器、Python/NumPy/PyTorch/CUDA
随机状态和数据打乱状态。原子替换避免半写文件损坏旧进度。续训保持训练协议不变，
从最近完整轮次继续；只允许增加总目标轮数或更换输出位置。
探针和配置搜索按批计算，末批按实际样本数加权；六线误差条只表示信道种子间标准差。

### D7 显式定位对照（2026-10-03）
保留基础层和预先约定的固定排名槽位宽；每个有增强数据的槽发送 ceil(log2(N)) 位块编号、
8 位 CRC（多项式 0x07，初值 0，高位先处理，无最终异或，编号补零到整字节）和奇数重复保护。
编号头与增强数据按固定槽序分别打包，不从受损编号推导任何读取长度。头校验失败、编号越界，
或多个校验有效记录争用同一编号时丢弃相应增强记录；冲突记录全部丢弃。基础层仍按空间位置解码。
该策略不保证零漏检，也不检测增强值自身的误码；仿真真值仅用于统计未检测的错投，不能帮助解码。

定位与保护开销从原预算扣减：按最低优先级槽依次减少增强位深，直到源载荷、编号、CRC 和重复冗余
之和不超过同一上限。这是固定启发式，不宣称最优分配；输出约定桶表及所有开销分项。
比较原分档、同精度扣减分档、显式定位、相同受损载荷的 oracle 定位，并补齐有噪声均匀基线。
均匀线与其他线共有预算上限；扣减分档为了隔离定位作用会少用定位开销对应的预算，需明确标注。
所有评估按样本 ID 派生随机流，显式定位与扣减分档共享基础层/增强层受损比特；不使用测试集选型。

D7 小样本结果（n=24，3 个信道种子）：6 dB 显式定位达到 62.5%，同精度隐式排序为 23.6%，
均匀量化为 55.6%；0 dB 显式定位为 40.3%，低于均匀量化的 58.3%。因此优先扩大验证并保留
均匀基线，不预设显式定位全面占优。原始记录在 `outputs/corrected/addressed_20261003/`。

### D8 固定配置的扩展验证
从 split_seed=0 的固定验证划分跳过前期 24 张，使用随后 96 张；显式检查与前期结果中的样本 ID
无交集。B=392、原桶/候选桶、块编号三重复保护、SNR=0/6/12、信道种子 0/1/2 全部固定。
先在每张图内平均各信道种子的正确性差值，再以图像为单位进行 10000 次百分位 bootstrap。
探索性 95% 区间只表示当前协议/分类器/已取信道种子条件下的图像抽样变化，不能作为训练方差、
模型选择不确定性或最终测试集性能的估计。本轮不调参、不训练、不使用最终测试集。

D8 结果：96 张图的 5184 条记录完整且满足预算，与前期 24 张无重叠。0/6/12 dB 显式定位相对
均匀量化分别为 -12.2/+20.1/+14.6 个百分点，探索性区间分别为 [-21.2,-3.5]/[9.7,30.6]/[4.2,25.0]。
6 dB 相对同精度隐式排序提高 37.2 个百分点，但在 288 次图像-种子组合中仍损害 5 次。
真值定位不是分类准确率上界：它保留受损增强值，偶发擦除可能让任务预测改善；实际发现一个这样的样本。
继续保留均匀基线，低 SNR 的像素载荷保护与修补仍待验证，不宣布桶配置最终定型。
详见 `outputs/corrected/addressed_validation96_20261003/findings.md`。

### D9 显式定位与均匀量化的修补训练
两种新模式共用残差网络结构，输入受损像素、实际解码位深和两个收端状态通道：每块是否收到
通过校验的增强，以及广播到所有块的整帧增强槽擦除比例。编号无效时其原始位置未知，不能使用
发送编号制造逐块擦除真值；位深为基础层也可能是原本就没有增强，两者不能混称“已定位丢失”。
均匀模式无增强槽，两个状态通道为零；两种新网络参数量相同。旧 bucket 模式保持原输入结构。

显式模式按总预算扣减候选桶精度；均匀模式使用先验固定深度，不调用注意力或发送分配图。
训练与推理共用相同损伤入口。权重记录传输模式、源预算、网格、编号保护、CRC 与收端状态定义，
拒绝新旧模式及不同保护设置混用。新模式的训练 SNR 由种子/轮次/批序号决定，独立于不同码流
消耗的噪声随机数，且续训可复现；旧 bucket 续训保留原轨迹。

四线入口加载两个分别训练的模型，在每种协议内部复用同一受损输入比较修补前后；检查两组
架构、训练/选优样本、初始化种子、批大小、损失、SNR 设置、已完成轮数与总预算相同。
最佳验证轮次可不同。默认评估固定验证划分中未用于修补训练或模型选优的图，最终测试需显式指定。
真实 CPU 冒烟只验证数值、梯度、保存与评估链路，不作为修补改善性能的证据。

### D10 固定容量的条件输入消融与运行矩阵
训练前指定 full/no_depth/no_receiver/none；所有参数及初始化顺序相同，通过零乘法屏蔽相应
嵌入贡献。网络配置保存该条件，续训不能更改；每个条件独立训练，不把测试时临时屏蔽当作训练消融。
关闭位深仍保留增强可用性信息，关闭收端状态仍保留实际位深；none 才同时关闭两种显式条件，
像素本身仍可能包含量化差异。参数总量相同不代表有效条件路径或可用信息相同。

每个训练种子预先固定六个模型：显式完整条件、关闭位深、关闭收端状态、仅受损图、单点 6 dB
训练以及均匀量化完整条件。前四种和均匀条件在 0–12 dB 训练；单点条件只改变训练 SNR，
所有模型按相同验证 SNR 列表选优。除明确声明的差异外，验证样本、训练轮数、损失和预算必须一致。
五个显式条件评估时只生成一份受损输入并共享；以图像为单位重采样完整条件减各对照的准确率差值。
探索性区间条件于本次训练得到的固定模型和信道种子，不包含训练方差和多重比较校正。

运行矩阵默认只生成计划，正式配置包含 3 个训练种子 × 6 个模型，逐种子保留结果；执行需指定
--execute，在目标训练机器串行运行。计划记录配置和源码校验值，变更后不能静默复用旧目录。
已验证完成的输出校验后跳过，失败训练可从最新完整轮次恢复；异常、部分评估或文件漂移停止后续步骤。
本机只执行 CPU 极小样本矩阵，正式研究消融仍保留未完成。
