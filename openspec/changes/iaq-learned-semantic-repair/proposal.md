## Why

重要性感知量化依赖比特分配信息。变长解析在分配信息受损时可能发生后续数据错位；
从基础层派生分配也不能自动解决变长读取边界的问题。本变更用固定桶帧结构稳定读取边界，
并研究学习式修补能否改善受损重建的分类表现。

固定边界不保证增强数据空间归属正确，残差修补不保证分类性能不下降；这些需要独立实验。
旧协议探针和历史曲线仅供追溯，新协议采用固定共享量化范围，必须重新训练与评估。

## What Changes

- 非级联粗桶编码：均匀基础层与固定大小、固定比特的增强桶，按接收端派生排序解码。
  分别诊断档位错配和增强数据归属错配，包括同桶内交换。
- 收端 patch-Transformer：受损重建与位深图作为输入，分类交叉熵为主、MSE 为辅。
  位深表示分配精度，不等于信道可靠性；零输出头只保证初始化恒等。
- `bucket` 与 `bucket+repair` 模式共享信道预算；配对评估报告救回率、修坏率和净增益。
- 六线使用共同信道比特上限，记录真实载荷、元信息、FEC 和免费辅助信息；
  匹配/失配结果不预设性能排序，启发式重复码不代表最优 FEC。
- 训练集/验证集/测试集分离；逐轮验证保存最优模型，最新完整轮次支持恢复优化器和随机状态。
- 探针与配置搜索按批读取；多信道种子结果保存标准差并绘制误差条。
- 增加显式块编号增强层对照：固定槽位边界、编号校验与重复保护、异常记录擦除，
  支付定位开销后与同精度隐式排序及有噪声均匀量化比较。小样本定位收益不等于全信噪比优势。
- 显式定位和均匀量化分别训练相同容量的修补器；新增收端可知状态，隔离传输模式权重，
  以相同训练 SNR 序列和轮数进行四线配对评估，默认排除修补训练与选优样本。
- 固定参数总量的条件输入消融、共享受损输入的多模型评估，以及预声明的六条件多种子训练计划；
  默认只生成计划，正式研究结果仍需真实训练后验证。

## Capabilities

### New Capabilities
- `iaq-bucket-coding`: 固定边界粗桶编码、收端排序、位深图及增强数据归属诊断。
- `iaq-semantic-repair`: 位深条件残差修补、任务目标训练、配对验证与可恢复训练。

### Modified Capabilities
- `iaq-pipeline`: 增加 `bucket` / `bucket+repair` 模式与六线双场景评估。

## Impact

- 涉及粗桶、管线、修补网络、共享实验工具及训练/评估脚本。
- 复用冻结 ViT、CIFAR-100、AWGN/BPSK 与重复码；当前不新增强纠错码或可靠性预测模型。
- `iaq` 调用入口保留，但默认量化协议改变；历史数值结果和缺少协议信息的权重不能直接迁移。
- 本机仅进行 CPU 小样本逻辑验证；真实训练、完整消融与正式测试仍待完成。
- 当前变更保留未完成状态，不将工程实现通过等同于研究假设已得到验证。
