## Decisions

### D1 公式体系
- 信源图像 x ∈ R^(H×W×C)，patch 数 N=196
- 注意力分数 a_i，M_i 为第 i 个 patch 的量化比特数
- 元信息 M = [M_1, ..., M_N]；过信道后 M̂ = [M̂_1, ..., M̂_N]
- 游标偏移量 δ_k = M̂_k − M_k，累积偏移 Δ_k = Σᵢ₌₁ᵏ δ_i
- 信噪比 Eb/N0，误码率 p_e
- 与代码中的变量名保持对应（方便后续论文照搬）

### D2 图表选入原则
